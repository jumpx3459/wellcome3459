# 관리자 화면 1단계 — 배치 개선 (지시서 보관, 2026-10-25 대표)

조사·설계안 보고 후 대기, 코드 변경 없음. 로직·API·DB 변경 없음이 전제.

## 배경(대표 검토 10/25)
지표가 업무 카드보다 위에 있어 매일 쓰는 카드까지 두 화면 넘게 스크롤. KPI 기록 표 30행·카테고리 표가 세로 공간 차지,
masonry라 카드 위치가 높이에 따라 바뀜, "조치 필요"가 작은 회색 한 줄, [삭제]가 [마감] 옆에 같은 크기, 보조 글씨가 작고 흐림.
매니저 합류 전에 "일하는 화면"을 먼저 보이게 하는 것이 목적.

## 조사
1. /admin 섹션·카드 전체 목록: 이름, 현재 순서, PC 열 배치 방식(columns-3 masonry), 기본 접힘 상태, 사용 컴포넌트(AdminListCard 여부).
2. KPI 기록 표·카테고리별 현황 표: 행 수, 데이터 출처, 접기 가능 여부.
3. "조치 필요" 현재 표시 방식(#110 NeedsAction)과 0건일 때 표시.
4. 매물 카드 [수정]/[마감]/[삭제] 렌더 위치, [삭제] 권한(super 전용 여부).
5. 13px 미만 글자·대비 4.5:1 미만 회색 글자 위치 목록(헤더 링크, 판매자 신청 정보, 사업자 조회 이력 포함).

## 설계안(확정 범위 기준, 파일·컴포넌트 단위)
1. 순서: 조치 필요 → 업무 카드 → 지표(핵심 지표·7일 추세·참고 현황·KPI 표·카테고리 표).
2. 조치 필요: 1건 이상이면 큰 숫자 타일, 0건이면 "모두 처리됨" 한 줄.
3. PC 고정 3열(masonry 대신):
   - 좌 = 관심 표시한 회원·이런 재고 찾습니다(구매 요청)·거래 연결
   - 중 = 대기 중인 판매자 신청·진행 중인 매물·판매자 대신 등록(+새 매물 직접 등록·긴급 공지 등록 버튼)
   - 우 = 사업자 조회(기본 접힘)·공식 점핑파트너 신청·점핑파트너 실적·최근 가입 회원·관리자 목록
   - 360 폭은 같은 순서로 1열.
4. 상단 고정 바로가기 칩: 조치·매물·구매요청·회원·지표 → 해당 섹션으로 스크롤(sticky, safe-area 고려).
5. KPI 표 최근 7행 + [전체 보기], 카테고리 표 기본 접힘.
6. [삭제] → ⋯ 메뉴 안으로(기존 확인 절차·권한 그대로).
7. 대기 중인 판매자 신청 1건 이상이면 자동 펼침 + 주황 배지(AdminListCard 배지 규칙).
8. 13px 미만·대비 미달 글자 일괄 보정.
9. AdminListCard 밖 제목 3개(사업자 조회·긴급 공지 등록·관리자 목록) 제목 줄 스타일 통일.

## 범위 밖
지표 통합·숫자 기준 변경(PR-C2), 전화번호 가림, 회원 화면.
